Understanding Cryptographic Avalanche Effect

In cryptography, the Avalanche Effect refers to a property where a tiny change in the input (like changing a single letter from lower to uppercase) results in a completely random and vastly different output hash. This represents the **Integrity** aspect of the CIA Triad.

Because hashing functions are one-way, knowing the hash does not reveal the password. However, when you verify a password, the system hashes your input and compares it to the stored hash. If even one character is incorrect, the output changes so drastically that the hashes fail to match, guaranteeing that the original message integrity has not been altered.
